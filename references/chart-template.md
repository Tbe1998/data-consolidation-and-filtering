# 监测曲线图批量统一版式（模板与操作规程）

来源：2026-11 杭州地铁 110 二期 X3# 井监测曲线数据册（47 张图）的返工实录。
用户在 Excel 里手调好了「每组第一张」，要求其余图照抄；随后又追加了三条修改。
这里把结论固化成模板，下次同类任务直接套。

## 1. 一页纸模板规格

| 项目 | 时程曲线（图1） | 测斜曲线（图2） |
|---|---|---|
| 图幅 | **186 × 56 mm**（A4 通栏） | **90 × 210 mm**（A4 半栏通高） |
| 导出 | 220 dpi PNG（1610×484 / 779×1818 px） | 同左 |
| 图数 | 每张 ≤ **5 条**测点曲线 | 每孔 1 张，**6 期**日期曲线 |
| 图名 | `<项目> <测项> 时程曲线` | `<项目> <孔号> 时程曲线图` |
| 图名禁忌 | 不带 `（mm）（m）（kN）`、不带 `1/4` 这类序号 | 不写「位移-深度曲线」 |
| 图例 | 图下方居中、无边框 | **右下角**空白区、白底 |
| 坐标轴 | X 日期、Y 累计变化量；Y 轴标题保留单位 | **位移轴在顶部**、**深度轴在左**、深度向下增大（`maxMin`） |
| 字号（Excel 内） | 标题 16 pt、轴标题 12 pt、图例 14 pt | 同左 |
| 线条 | 折线 + 圆点标记，标记白边 | 同左 |

时程图常用绘图区几何（Excel `manualLayout`，x/y/w/h，y 自顶部计）：
`0.0674, 0.0676, 0.8799, 0.9206`；测斜图图例框：`0.6896, 0.8373, 0.3066, 0.1608`。
这两个值不是金科玉律——**永远以用户手调好的那张基准图为准**，脚本负责复制。

## 2. 谁抄谁、谁保留

套版式时只搬运「外观」，不搬运「内容和身份」：

| 元素 | 来自 | 说明 |
|---|---|---|
| 绘图区 geometry、图例块、坐标轴刻度/数字格式 | **基准图** | 组内所有图必须一致 |
| 图名格式（字体/字号/位置） | **基准图** | 文字用本图的 |
| 图名文字 | **本图**（清洗后） | 去单位、去 `n/m`、按需改名 |
| 轴的 `axId` / `crossAx` | **本图** | 用基准的 ID 会让 Excel 认为轴和系列断链 |
| 轴标题文字 | **本图** | 但字号/颜色跟基准 |
| 数据 `numRef` / `numCache` | **本图，一字节不动** | 脚本跑完必须做零改动校验 |
| 图例系列名 | **本图** | 抄基准的图例时务必删掉 `<c:legendEntry>` |

### 量程保护（关键）

基准图量程抄过去之前先比一下：若本图原量程 < 基准量程的 **40%**，保留本图刻度。
典型场景：支撑轴力前 3 张测值几千 kN，后 4 张只有 600~1500 kN，
硬套 `-4000~6000` 会变成一条贴底的直线。该保留的图要在报告里点名，别静默处理。

其余情况按「基准步长 + 本图数据外扩」：数据超出基准 `min/max` 时，
按基准 `majorUnit` 一格一格往外扩，直到包住全部数据点。

## 3. 可复用命令

```bash
# 1) 先看结构，生成配置草稿（每页一张图也会列出来）
python3 scripts/xlsx_chart_uniform.py --init 曲线图.xlsx > chart.json

# 2) 编辑 chart.json：把同组的页并进一个 group，ref 指向手调好的那张
#    测斜这种「每页一张」的组，直接列 10 个页名，ref=0 指向 TST1

# 3) 套版式（原文件不动；退出码 2 表示有图数据被改动，必须查）
python3 scripts/xlsx_chart_uniform.py 曲线图.xlsx 曲线图_统一版式.xlsx -c chart.json

# 4) 导出 PNG
python3 scripts/xlsx_charts_to_png.py 曲线图_统一版式.xlsx out/png \
    --dpi 220 --time-size 186x56 --incl-size 90x210 --time-sheets '图1*'
```

配置里几个容易忽略的键：

```json
{
  "strip_units": true,          // 图名去掉末尾的（mm）（m）（kN）
  "strip_index": true,          // 图名去掉 1/4、2/18 这类序号
  "axis_min_span_ratio": 0.4,   // 量程保护阈值
  "clean_strings": {"contains": ["[数据页"], "strip_units": true, "strip_index": true},
  "groups": [{
    "name": "测斜",
    "sheets": ["图2 测斜TST1", "图2 测斜TST2"],
    "ref": 0,
    "rename": {"位移-深度曲线": "时程曲线图"},
    "legend_dates": {"row": 2, "from_col": 2, "count": 6}
  }]
}
```

`legend_dates` 把系列名从 Excel 日期序列号（45503）改成 `2024-07-30`，
并把公式改成引用表头单元格（`'图2 测斜TST1'!$B$2`）——以后改表头日期，图例自动跟。

## 4. 交出去之前的校验（照抄这四条）

1. **数据零改动**：逐图比对源文件与输出文件的 `<c:numCache>`，必须全部一致。
   脚本已内置，退出码非 0 就是有图被改了。
2. **图名集合**：输出全部图名 vs 期望清单，差异为 0；说明页的图名清单也要同步。
3. **组内样式唯一**：每组绘图区 `manualLayout`、图例块、轴 `min/max/majorUnit`
   各只应有一种取值（量程保护的那几张单独列出）。
4. **读回验证**：用 openpyxl 打开输出，确认工作表数量、图表数量、共享字符串正常；
   再把 PNG 抽 2~3 张目视（标题/轴标题/图例有无重叠或裁切）。

## 5. 坑（都是踩过的）

- **不要硬编码 `chartN.xml`**：chart 编号跟创建顺序有关，换一版文件就错位。
  按 `workbook.xml → sheet rels → drawing rels → chart rels` 解析。
- **替换轴之后要重取偏移量**：`axes(s)` 的位置在每替换一个 `valAx` 后都会变，
  循环里必须重新取，否则第二个轴会切错位置（表现为少一个轴/图例错位）。
- **图例要删 `legendEntry`**：直接复制基准 `<c:legend>` 会把基准图「隐藏某系列」的设置带过来。
- **图名的顺序**：`…时程曲线（mm）2/3` 里单位在序号前面，**先删序号再删单位**；
  否则单位正则匹配不到结尾。
- **说明页文字在 `sharedStrings.xml`**，不在图表里。单位可能出现在字符串中间
  （`名称（mm） 1/4 [数据页:…]`），这里要用「任意位置的括号单位」正则，不能锚定结尾。
- **单位口径冲突要单独确认**：地下水位图 Y 轴标题写「（m）」，数值却是 −8000~4000 mm；
  这类矛盾不要自行改数，也不要只改轴标题了事，先问。
- **matplotlib 中文**：容器里 WenQuanYi Zen Hei 只有 500 字重，`fontweight='bold'`
  会刷 `findfont: Failed to find font weight bold` 警告但不影响出图；
  需要真粗体就换 Noto Sans CJK Bold。
- **测斜图方向**：`Series(y=深度, x=位移)` + `orientation="maxMin"`，写反就是一条对角斜线。
- **PNG 图例压线**：测斜图图例放右下角前，先用数据点包围盒判断是否有点落在图例框内；
  10 张图 × 480 点全检一遍，成本很低（本案例结果 0/480）。

## 6. 深度剖面：曲线数量自适应（不固定 6 条）

测斜/沉降剖面有 10~131 期时，全画会糊，固定取 6 期又可能漏掉中段转折。用「线性插值
重构误差」决定张数：需要几张就出几张，但每张都得提供新信息。

```bash
python3 scripts/pick_profile_curves.py tst2.csv            # 首列深度、其余列表头为日期
# → 选点 + 峰值 + 阈值 + 最大重构误差（JSON）；--format text 看人话版
```

规则：

1. **首测 / 末测 / 峰值期必选**；
2. 反复找「与左右两张已选曲线线性插值差得最远」的中间期，差值 > tol 就加入；
3. 相邻两张剖面最大差值 < 1.5 mm 视为视觉重复（首/末/峰值除外）→ 删信息量小的；
4. 不足 5 张时按最大时间间隔补点；
5. `tol = max(2.0 mm, 峰值 × 10%)`，上限 9 张。

出图时的配套约定（避免 8~9 条挤成一团）：

- **峰值曲线加粗 + 洋红**（`#B2182B`），它是包络线，必须一眼找到；
- **峰值之后的曲线用虚线**，把「回落期」和「增长/平台期」分开，图例标题注明「虚线=峰值后」；
- 只在首/峰/末三条上打标记，中间曲线纯线，减少噪声；
- 图例放到图下方（2 列，最多 5 行），按实际条数动态留白。
X 轴上限规则（用户 2026-11 明确要求）：从 **1.5×峰值** 起向上取整到最近的十位，
落在峰值的 **1.5~2.5 倍**；上限 >30 时刻度间隔改 10 mm。实现：
`hi = 10*ceil(1.5*max/10)`，若 `hi > 2.5*max` 且退一档仍 ≥1.5× 则退一档。
负值：下限按 **1.5×|最小值|** 向下取整到 5 的倍数（如 −1.73 → −5），自动化测斜管口
（深度 1~3 m）常出现负值，按 0 起画会把管口段裁掉。渲染函数在保存前必须断言
「所有绘制点 ∈ [lo, hi]」，越界就自动扩轴并告警——不要靠人眼看。

## 7. 本案例规模（用于估算工时）

110 二期 X3# 井：19 个工作表、47 张图、9 个组。
- 时程：地表 4 / 管线 18 / 建筑物 3 / 压顶梁沉降 1 / 压顶梁水平位移 1 / 水位 2 / 倾斜 1 / 轴力 7
- 测斜：TST1–4、ZDH-CX1/2、ZQT1–4，每孔 6 期（2024-07-30 → 2025-05-17）
- 数据跨度：2024-07-30 → 2025-05-14
- 套版式 + 图名清理 + 图例改日期：一轮脚本 1~2 分钟；校验（47 张逐图对比）另 1 分钟
