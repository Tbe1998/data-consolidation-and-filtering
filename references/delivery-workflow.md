# 监测曲线「一条龙」交付工作流

从一堆监测日报/汇总表到 4 个交付件（曲线图 PDF + 3 张 Excel），全流程脚本化。
本文是踩过坑后的定稿版本，照做即可复现；参数以 110 二期 X3# 井为实例（19 个工作表、47 张原始图）。

---

## 0. 产出物与验收口径

| 文件 | 内容 | 验收点 |
|---|---|---|
| `<项目>_曲线图.pdf` | 封面 + 时程曲线（4 张/页）+ 测斜全过程曲线（1 页/孔） | 页数 = 1 + ⌈时程数/4⌉ + 孔数 |
| `<项目>_数据汇总表.xlsx` | 全部采集数据：测项宽表 + 测斜矩阵 + 原始附页 | 行数与原表一致，不补 0 |
| `<项目>_筛选后数据汇总表.xlsx` | 按图分块：每块 = 该图 PNG + 绘图数据 | 块数 = 时程图数 + 孔数，图片数一致 |
| `<项目>_各点最大累计值汇总表.xlsx` | 每点绝对值最大的累计值 + 出现日期（测斜另给深度） | 行数 = 测点数 + 孔数 |
| `<项目>_曲线图_PNG.zip` | 全部 PNG 源文件 + `_索引.csv` | 张数 = 时程 + 孔数 |

命名统一 `<项目>_<类型>`；PNG 带 `01_` 序号，索引里写明图名/图幅。

---

## 1. 输入与前置检查

- 原始曲线工作簿（Excel 内嵌图表）——版式基准来自它；
- 监测数据汇总（测项宽表 + 测斜矩阵）；
- 输出目录：`output/<项目>-curves/`。

先确认三件事，否则后面全白做：

1. **宽表方向**：测项表是「点号→列、日期→行」还是反过来。实测多数是 `A 列点号、第 2 行日期、第 3 行起数据`。
2. **测斜矩阵**：`A 列深度`、第 2 行日期、第 3 行起数值；表头常是**合并单元格**，先打印前 4 行 + `merged_cells.ranges` 再取列。
3. **缺测口径**：没测 ≠ 测得 0。空就是空，不插值、不补点。

---

## 2. 图表统一版式（Excel 内嵌图表）

`.xlsx` 就是 zip，图表在 `xl/charts/chartN.xml`。改 XML 比手动点快两个数量级，且能做到数据零改动。

```bash
python3 scripts/xlsx_chart_uniform.py --init 曲线图.xlsx > chart.json   # 探结构
# 编辑 groups：哪些页一组，ref 指向手调好的那张
python3 scripts/xlsx_chart_uniform.py 曲线图.xlsx 输出.xlsx -c chart.json
```

规则：
- **只抄外观，不抄身份**：绘图区几何 / 图例块 / 轴刻度 / 标题格式 ← 基准图；
  `axId`、轴标题文字、图名文字、数据 ← 本图。
- 复制图例必须删 `<c:legendEntry>`，否则颜色错位。
- **必须校验**：逐图比对输入输出的 `<c:numCache>`；脚本退出码 2 = 有图数据被改，必须查。
- 量程保护：本图原量程 < 基准 40% 的保留本图刻度，其余按基准 `majorUnit` 逐格外扩包住数据。
- 图名清洗：先删 `1/4` 这类序号，再删结尾的 `（mm）`——单位常躲在序号前面。

## 3. 曲线重绘（PNG）

```bash
python3 scripts/xlsx_charts_to_png.py 统一版式.xlsx out/png --dpi 220 \
    --time-size 186x56 --incl-size 90x210 [--debug]
```

**样式（时程与测斜共用）**
- 图幅：时程 186×56 mm；测斜 90×210 mm（图例右下、位移轴在顶、深度向下）。
- 线条：一律**实线**，不用虚线区分阶段。
- 颜色：9 色 Okabe-Ito 扩展板
  `#0072B2 #E69F00 #009E73 #CC79A7 #56B4E9 #D55E00 #7B5EA7 #8C564B #000000`。
- 标记：9 种**空心**异形 `o s ^ D v P X * h`，`mfc=white`，`markevery` 错位——黑白打印也能认曲线。
- 图例标题只写「观测日期」，**不带括号说明**；图下不放任何说明性小字。

**纵轴（时程）**
- 按数据算：`1.5×极值` 起，取 nice 步长（1/2/5×10ⁿ），有负值同步下扩；
- 组内共用轴（原模板要求），跨度 <组内最大跨度 40% 的图保留自身范围，否则曲线被压平（轴力小量程常见）；
- 保存前断言所有点 ∈ [lo, hi]，越界自动扩轴并告警——**不允许出现“图看着对、实际被裁”**。

**横轴（测斜）**
- `hi = 10×⌈1.5×max/10⌉`，落在峰值 1.5~2.5 倍；若 >2.5× 且降一档仍包住数据，则降一档；
- 负值下限 `-5×⌈1.5×|min|/5⌉`（自动化测斜管口常有 −1~−2 mm）；
- 上限 >30 时刻度间隔 10 mm，否则 5 mm；
- 唯一例外：峰值 7.9 这类取整后只能 1.27× 或 2.53× 的，取 2.53× 并在交付说明里标注。

**曲线条数（测斜，别固定 6 条）**
- 首测 / 末测 / 峰值必选；
- 反复加「线性插值重构误差最大」的那一期，直到误差 ≤ max(2 mm, 峰值×10%)；
- 相邻剖面差 <1.5 mm 视为重复，删；
- 上限 9 条、下限 5 条（不足按时间补）。实测 10 个孔落在 5~9 条。

## 4. 分类分块与自然排序

- **分类**：按测点前缀（`DB/DL/JS/RQ/TX/WS/YS`、`TST/ZDH-CX/ZQT`）分组；
- **块大小**：类内每 5 个测点一张图（轴力这类一点一图的不合并）；
- **排序**：自然序 `DL1、DL2…DL9、DL10`，不能按字符串（会成 `DL1、DL10、DL11…DL2`）；
  `DB1-1` 这种带横杠的按数字段逐段比较；
- **命名**：图名带范围，如 `管线沉降 时程曲线 DL1~DL5`；
- 渲染后写 `_groups.json`：每张图的图名/文件/测点/日期/数据，供后续表格复用。

## 5. 四件套生成

```bash
python3 scripts/make_delivery.py \
  --summary 汇总.xlsx \
  --groups out/png/_groups.json \
  --charts out/png --incl out/incl \
  --sel 选点说明.json \
  --title "110二期X3#井" --out deliverables
```

- **数据汇总表**：整本复制，测项行按自然序重排，表头样式统一；不做任何数据加工。
- **筛选后汇总表**：按 `_groups.json` 一块一块写——先图（186×56 mm，留 12 行 ≈ 63 mm）、
  再「日期为行、测点为列」的绘图数据；测斜每孔先图（90×210 mm，留 40 行）、图下是深度×选定日期。
- **最大累计值**：逐点取 `abs` 最大并保留符号，记录出现日期；测斜另记出现深度；期数=有数的日期数。
- **PDF**：封面 + 时程 4 张/页 + 测斜 1 页/孔；测斜图按 90×210 mm 落到 220 dpi 画布（源图 300 dpi，必须缩放，否则铺成 122×286 mm）。
- **PNG 包**：按序号改名 + `_索引.csv`（序号/类型/图名/文件/图幅）。

## 6. 一条龙命令

```bash
# 1) 统一版式
python3 scripts/xlsx_chart_uniform.py 原图.xlsx 统一版式.xlsx -c chart.json
# 2) 重绘 PNG（含 _groups.json）
python3 scripts/xlsx_charts_to_png.py 统一版式.xlsx out/png --dpi 220

python3 scripts/pick_profile_curves.py 测斜.csv --format text
# 4) 四件套
python3 scripts/make_delivery.py --summary 汇总.xlsx --groups out/png/_groups.json \
    --charts out/png --incl out/incl --sel 选点说明.json --title "<项目>" --out deliverables
```

## 7. 交付前校验清单

1. PNG 张数 = 时程图数 + 孔数；PDF 页数 = 1 + ⌈时程/4⌉ + 孔数。
2. 每张图轴范围都包住数据（脚本已断言，抽 3 张复核）。
3. 图例只有「观测日期」；图名无单位、无序号、无括号说明；图下无小字。
4. 转灰度看一遍：8~9 条曲线靠标记形状能区分。
5. 筛选表块数、图片数、块内测点数（≤5）与图一致。
6. 最大累计值抽查 2 个点，与汇总表逐值核对。
7. 排序：`DL2` 必须在 `DL10` 前；`DB1-10` 在 `DB1-9` 后。
8. 单位：倾斜 ‰、轴力 kN、沉降/位移/水位 mm；水位轴标题若写 (m) 而数据是 mm，交付时说明，不擅自改。

## 8. 坑（都踩过）

| 现象 | 原因 | 处理 |
|---|---|---|
| `IndexError` 读测斜表头 | 表头是合并单元格 | 先打印前 4 行 + merged ranges |
| 替换一个 `valAx` 后轴全乱 | 字符偏移 | 每轮重新 `axes(s)` 取目标轴 |
| 图表数据被改 | 误改 `numCache` | 逐图比对，退出码 2 就回滚 |
| 中文 bold 刷 `findfont` 警告 | matplotlib 中文字体只有 500 字重 | 忽略警告，不影响出图 |
| 负值被裁 | 只按峰值算了上限 | 下限按 `1.5×|min|` 单独算 + 越界断言 |
| Excel 里图片巨大 | openpyxl 按图片原生像素写 | 显式设 `img.width/height`（96 dpi 换算），或直接看 `<ext cx cy>` 核尺寸 |
| 公式返回空写成 `NA()` | 图上会断点 | 用 `""`；且注意 Python 里别让转义把引号吃掉 |
| PDF 里测斜图铺满页 | 300 dpi 源图直接贴 220 dpi 画布 | 贴图前 resize 到 90×210 mm |
| 测点 1、10、11…2 | 字符串排序 | `natkey` 自然序，图表分组与表格同步 |
| 明细/检查表被当成测项 | 只按表名排除 | 用「第 2 行是 点号+日期」判据 |

## 9. 实例规模（估工时用）

110 二期 X3# 井：19 个工作表、47 张原始图（时程 37 + 测斜 10）。
- 统一版式 + 图名清理：1~2 分钟；
- 重绘 49 张 PNG（分类分块后时程 39 张）：约 1 分钟；
- 四件套生成：约 1 分钟（筛选表 4.4 MB，含 49 张图）；
- 校验：3~5 分钟。
- 数据区间 2024-07-30 ~ 2025-05-17；早停药孔 TST1(08-20)/ZQT4(08-16)/ZDH-CX1(11-30)/ZDH-CX2(12-03)。
